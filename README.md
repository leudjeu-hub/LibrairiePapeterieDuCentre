# LibrairiePapeterieDuCentre
Site de commande et de livraison pour la Librairie Papeterie du Centre (Yaoundé).

Site statique (HTML/CSS/JS, sans build) repris d'Emergent (papeterie-mobile.emergent.host) le 16/11/2026.

- `js/config.js` : WhatsApp, téléphone, commande minimum, moyens de paiement, familles
- `js/delivery.js` : zones, frais, minimum et livraison offerte par zone
- `js/products.js` : catalogue (773 articles)

Test local : `python3 -m http.server` puis http://localhost:8000
